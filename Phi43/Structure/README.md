# Finite Φ⁴₃ regularity structure

This directory contains the explicit finite regularity structure for the dynamical Φ⁴₃ equation,
its renormalisation group, the canonical and renormalised models of a smooth periodic noise, and a
finite planted integration completion of the structure used by the fixed point. The main source is
M. Hairer, *A theory of regularity structures*, Invent. Math. 198 (2014), arXiv:1303.5113v4
([Hai14]); polynomial weights follow M. Hoshino, *A semigroup approach to the reconstruction
theorem and the multilevel Schauder estimate* ([Hos25]). The design choices are explained in
the design notes next to this file.

## Parameters

The parameter is `κ ∈ (0, 1/16)` (`Kappa`, `kappa₀`), with `α = |Ξ| = -5/2 - κ`. In [Hai14,
Section 9.4] the fixed-point cutoff must satisfy `γ > |2α + 4| = 1 + 2κ`. We choose
`gamma κ = 1 + 3κ`, which lies below `|I(Ψ)| = 3/2 - κ` on this interval (`gamma_lt_iPsi`). The
standalone symbol `I(Ψ)` is retained because it occurs in the renormalisation table [Hai14, (9.3)],
although it lies above the fixed-point cutoff. The products `I(Ψ)Ψ` and `I(Ψ)Ψ²` retain their
spatial Taylor terms.

The polynomial symbols are excluded from the non-integrality statement. A larger structure would
contain further resonances: for example the cubic `I(Ψ³)³`, which is not retained, has homogeneity
`3/2 - 9κ` and is an integer at `κ = 1/18`. The intermediate results on the convergence of the
models assume `κ ∉ Statements.excludedKappa`, a finite set that contains every such resonance of
a non-polynomial symbol of degree at most four in the full Φ⁴₃ structure.

The character-level renormalisation conditions are in `Phi43.Structure.HairerCompatibility`. The map
`M` is not justified by a conjugation identity: the module gives the induced character map
(`plusCharacter`, `deltaM`) and the finite forms of [Hai14, (8.35b), (8.35c), (9.4b,c)]. The term
`1 ⊗ XᵢJᵢ(Ψ)` is supplied by `Δ(I(Ψ))` itself, so it does not appear again in the renormalisation
table. The constants `C₁` and `C₂` (`RenormalisationConstants`) are real parameters here; their
identification with [Hai14, (10.33), (10.41)] is made in the probabilistic part.

## The smooth canonical and renormalised models

The analytic construction assumes an explicit polynomial envelope on the iterated derivatives of
order `0` to `4` of the noise (`canonicalNoise_polyBounded_of_derivatives`); this is the growth
condition of the weighted framework [Hos25, Definition 2.1, (2.1)–(2.2)] and is stronger than the
local smoothness hypothesis of [Hai14, Proposition 8.27]. No time cutoff or localisation is used.
`Phi43.Structure.CanonicalSmoothAll` collects the results on the canonical lift and
`Phi43.Structure.RenormalisedExtensionAll` those on the renormalised model.

## Enlarged integration completion

In the original structure the cubic block `{Ψ, Ψ², Ψ³}` cannot be used to instantiate the fixed
point: commutation of the block projection with the structure group is incompatible with
polynomial admissibility. `Phi43.Structure.EnlargedAll` therefore exports a separate finite planted
completion `SymbolF`, which contains all original symbols and twelve new integrals: `I(ΨXᵢ)`,
`I(Ψ²Xᵢ)`, `I(I(Ψ)Ψ)`, `I(I(Ψ)Ψ²)`, `I(I(Ψ²)Ψ)`, `I(I(Ψ²)Ψ²)`, `I(I(Ψ³)Ψ)` and `I(I(Ψ³)Ψ²)`.
Integration is nonzero on these original products and zero on the planted symbols and the
polynomials. This is a finite integration completion, not an enumeration of the full degree-four
tree algebra.

The extension is built from the source sector `{Ψ, Ψ², Ψ³}` because the abstract extension theorem
requires source degrees above `-2`, which excludes the raw noise. The resulting model realises the
lifted source sector and the full `Ξ`-free integration map. The stronger statement `IsRealisingP`
on the whole `Ξ`-free block is false, because the block contains polynomial symbols on which the
explicit integration map is zero.
